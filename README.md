# ಕನ್ನಡ ಪದ ಗುರುತಿಸುವಿಕೆ ಮೌಲ್ಯಮಾಪನ

ಮಕ್ಕಳ ಓದು-ಸಂಬಂಧಿತ ಸಂಶೋಧನೆಗಾಗಿ ಕನ್ನಡದ ನಿಜವಾದ ಪದಗಳು ಮತ್ತು ಕಲ್ಪಿತ ಪದಗಳನ್ನು ಗುರುತಿಸುವ ವೆಬ್-ಆಧಾರಿತ ಮೌಲ್ಯಮಾಪನದ ಸ್ವತಂತ್ರ ಆರಂಭಿಕ ಆವೃತ್ತಿ.

> **ಪ್ರಸ್ತುತ ಸ್ಥಿತಿ:** ಇದು ಪರಿಶೀಲನೆಗಾಗಿ ನಿರ್ಮಿಸಿದ ಕಾರ್ಯನಿರ್ವಹಣೆಯ ಪ್ರೋಟೋಟೈಪ್. ನೈಜ ಸಂಶೋಧನಾ ಭಾಗವಹಿಸುವವರ ಮಾಹಿತಿಯನ್ನು ಸಂಗ್ರಹಿಸಲು ಅಥವಾ ಕ್ಲಿನಿಕಲ್/ಶೈಕ್ಷಣಿಕ ನಿರ್ಧಾರಗಳಿಗೆ ಬಳಸಲು ಇನ್ನೂ ಅನುಮೋದಿತವಲ್ಲ.

## ಯೋಜನೆಯ ಉದ್ದೇಶ

ಪರೀಕ್ಷಕನು ಭಾಗವಹಿಸುವವರ ಕೋಡ್ ಮತ್ತು ಸೆಷನ್ ಆಯ್ಕೆಮಾಡಿ ಪರೀಕ್ಷೆಯನ್ನು ಪ್ರಾರಂಭಿಸಬಹುದು. ಮಗುವಿಗೆ ಪರದೆಯ ಮೇಲೆ ಒಂದೊಂದು ಕನ್ನಡ ಪದ ತೋರಿಸಲಾಗುತ್ತದೆ. ಆ ಪದ ನಿಜವಾದ ಕನ್ನಡ ಪದವೇ ಅಥವಾ ಕಲ್ಪಿತ ಪದವೇ ಎಂದು ಮಗು ಆಯ್ಕೆಮಾಡುತ್ತದೆ. ಪ್ರತಿಯೊಂದು ಪ್ರತಿಕ್ರಿಯೆಯೂ ಪರೀಕ್ಷಾ ಸೆಷನ್, ಪದ ಮತ್ತು ಪ್ರತಿಕ್ರಿಯಾ ಸಮಯದೊಂದಿಗೆ ದಾಖಲಿಸಲಾಗುತ್ತದೆ.

## ಪ್ರಸ್ತಾವಿತ ಸಂಶೋಧನಾ ವಿನ್ಯಾಸ

- ಒಟ್ಟು ಪರೀಕ್ಷಾ ಪದಗಳು: **540**.
- ನಿಜವಾದ ಕನ್ನಡ ಪದಗಳು: **270**.
- ಕಲ್ಪಿತ ಕನ್ನಡ ಪದಗಳು: **270**.
- ಒಟ್ಟು ಸೆಷನ್‌ಗಳು: **6**.
- ಪ್ರತಿ ಸೆಷನ್: **90 ಪದಗಳು** — 45 ನಿಜವಾದ ಪದಗಳು ಮತ್ತು 45 ಕಲ್ಪಿತ ಪದಗಳು.
- ಪ್ರತಿ ಸೆಷನ್ ಆರಂಭದಲ್ಲಿ: **5 ಅಭ್ಯಾಸ ಪ್ರಶ್ನೆಗಳು**.
- ಪ್ರತಿ 15 ಅಂಕಿತ ಪರೀಕ್ಷಾ ಪ್ರಶ್ನೆಗಳ ನಂತರ: ಚಿಕ್ಕ ವಿರಾಮ.
- ಪ್ರಸ್ತಾವಿತ ಭೇಟಿಗಳು: **3**; ಪ್ರತಿ ಭೇಟಿಯಲ್ಲಿ 2 ಸೆಷನ್‌ಗಳು.

| ಭೇಟಿ | ಸೆಷನ್‌ಗಳು | ಅಂಕಿತ ಪದಗಳು |
|---|---|---:|
| 1 | 1 ಮತ್ತು 2 | 180 |
| 2 | 3 ಮತ್ತು 4 | 180 |
| 3 | 5 ಮತ್ತು 6 | 180 |

ಈ ಹಂಚಿಕೆ ಪ್ರಸ್ತುತ ಸಂಶೋಧನಾ ಪ್ರಸ್ತಾವನೆಯ ಆಧಾರದ ಮೇಲೆ ರೂಪಿಸಿದದ್ದು. ಅಂತಿಮ ಪ್ರೋಟೋಕಾಲ್ ಬದಲಾಗಿದರೆ ಸೆಷನ್ ಹಂಚಿಕೆಯನ್ನು ಸಂಶೋಧನಾ ತಂಡ ದೃಢೀಕರಿಸಬೇಕು.

## ಈಗಿರುವ ವೈಶಿಷ್ಟ್ಯಗಳು

- ಕನ್ನಡದ ಲಾಂಚ್ ಮತ್ತು ಸೂಚನಾ ಪರದೆಗಳು.
- ಡೆಮೊ ಮೋಡ್: 5 ಅಭ್ಯಾಸ ಪ್ರಶ್ನೆಗಳು ಮತ್ತು 18 ಪ್ರದರ್ಶನ ಪ್ರಶ್ನೆಗಳು.
- ಸಂಶೋಧನಾ-ಪೂರ್ವವೀಕ್ಷಣೆ ಮೋಡ್: ಸಂಶೋಧನಾ ತಂಡ ಒದಗಿಸುವ CSV ಪದಪಟ್ಟಿಯನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಬಹುದು.
- ಆರು ಸೆಷನ್‌ಗಳ ಮತ್ತು ಪ್ರತಿ ಸೆಷನ್‌ನ 45/45 ಪದ ಸಮತೋಲನದ ಪರಿಶೀಲನೆ.
- ಕೀಬೋರ್ಡ್‌ನ ಎಡ/ಬಲ ಬಾಣಗಳು ಮತ್ತು ಪರದೆಯ ಬಟನ್‌ಗಳ ಮೂಲಕ ಉತ್ತರಿಸುವುದು.
- ಪ್ರಗತಿ ಸೂಚಕ, ಅಭ್ಯಾಸ ಪ್ರತಿಕ್ರಿಯೆ ಮತ್ತು ಪ್ರತಿ 15 ಪ್ರಶ್ನೆಗಳ ನಂತರ ವಿರಾಮ.
- ಪ್ರತಿ ಟ್ರಯಲ್‌ಗೆ ಉತ್ತರ, ಸರಿತನ, ಪ್ರತಿಕ್ರಿಯಾ ಸಮಯ ಮತ್ತು ಸಮಯಮುದ್ರೆಗಳ ದಾಖಲೆ.
- ಪೂರ್ಣಗೊಂಡ ಪೂರ್ವವೀಕ್ಷಣೆಯ ಟ್ರಯಲ್‌ಗಳನ್ನು CSV ಆಗಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಬಹುದು.

## ಸ್ಥಳೀಯವಾಗಿ ಚಾಲನೆ

ಅಗತ್ಯವಿರುವುದು: Node.js 20 ಅಥವಾ ಅದಕ್ಕಿಂತ ಹೊಸದು.

```bash
npm install
npm run dev
```

ಬ್ರೌಸರ್‌ನಲ್ಲಿ Vite ತೋರಿಸುವ ಸ್ಥಳೀಯ ವಿಳಾಸವನ್ನು ತೆರೆಯಿರಿ.

ಪರಿಶೀಲನೆ ಮತ್ತು ನಿರ್ಮಾಣ:

```bash
npm run check
npm run build
npm run preview
```

## ಪದಪಟ್ಟಿ ರೂಪ

ಪದಪಟ್ಟಿಯನ್ನು `public/data/word-bank.csv` ಮಾದರಿಯಂತೆ ತಯಾರಿಸಿ. ಪ್ರತಿ ಸಾಲು ಒಂದು ಅಂಕಿತ ಪದವಾಗಿರಬೇಕು.

| ಕಾಲಮ್ | ಅರ್ಥ |
|---|---|
| `session` | 1 ರಿಂದ 6 |
| `item_id` | ಪ್ರತಿಯೊಂದು ಪದಕ್ಕೂ ವಿಶಿಷ್ಟ ಗುರುತು |
| `stimulus` | ಪರದೆಯಲ್ಲಿ ತೋರಿಸಬೇಕಾದ ಕನ್ನಡ ಪದ/ಕಲ್ಪಿತ ಪದ |
| `item_type` | `real` ಅಥವಾ `nonword` |
| `position` | ಆ ಸೆಷನ್‌ನ 1 ರಿಂದ 90 ಕ್ರಮಸ್ಥಾನ |

ಪ್ರತಿ ಸೆಷನ್‌ನಲ್ಲಿ 90 ಸಾಲುಗಳು, 45 `real`, 45 `nonword` ಮತ್ತು 1–90ರ ವಿಶಿಷ್ಟ ಕ್ರಮಸ್ಥಾನಗಳಿರಬೇಕು. ಎಲ್ಲಾ ಆರು ಸೆಷನ್‌ಗಳು ಸೇರಿ 540 ಸಾಲುಗಳಾಗಿರಬೇಕು. CSVಯಲ್ಲಿ ನಿಜವಾದ ಸಂಶೋಧನಾ ಪದಗಳನ್ನು ಸೇರಿಸುವ ಮೊದಲು ಭಾಷಾ ತಜ್ಞರು ಮತ್ತು ಸಂಶೋಧನಾ ತಂಡ ಅವನ್ನು ಪರಿಶೀಲಿಸಬೇಕು.

## ಡೇಟಾ ಮತ್ತು ಗೌಪ್ಯತೆ

ಈ ಪ್ರೋಟೋಟೈಪ್ ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಆ ಬ್ರೌಸರ್‌ನ `localStorage` ನಲ್ಲಿ ತಾತ್ಕಾಲಿಕವಾಗಿ ಉಳಿಸುತ್ತದೆ ಮತ್ತು ಬಳಕೆದಾರರು CSVಯಾಗಿ ಡೌನ್‌ಲೋಡ್ ಮಾಡಬಹುದು. ಇದು ಹಂಚಿದ ಡೇಟಾಬೇಸ್ ಅಲ್ಲ; ಬೇರೆ ಸಾಧನಗಳಿಗೆ ಮಾಹಿತಿ ಸಿಂಕ್ ಆಗುವುದಿಲ್ಲ. ಆಕ್ಸೆಸರ್ ಖಾತೆಗಳು, ಪಾತ್ರ ಆಧಾರಿತ ಅನುಮತಿ, ಸುರಕ್ಷಿತ ಸರ್ವರ್ ಸಂಗ್ರಹಣೆ, ಆಡಿಟ್ ಲಾಗ್, ಬ್ಯಾಕಪ್ ಮತ್ತು ಅನುಮೋದಿತ ಸಂಶೋಧನಾ ಡೇಟಾ ನಿರ್ವಹಣೆ ಇನ್ನೂ ಜೋಡಿಸಬೇಕಿದೆ.

**ನೈಜ ಮಕ್ಕಳ ಹೆಸರು, ಜನ್ಮದಿನಾಂಕ, ಸಂಪರ್ಕ ವಿವರಗಳು ಅಥವಾ ಗುರುತಿಸಬಹುದಾದ ಸಂಶೋಧನಾ ಮಾಹಿತಿಯನ್ನು ಈ ಡೆಮೊದಲ್ಲಿ ನಮೂದಿಸಬೇಡಿ.** ಪರೀಕ್ಷೆಗೆ ಕಲ್ಪಿತ ಭಾಗವಹಿಸುವವರ ಕೋಡ್ ಮಾತ್ರ ಬಳಸಿ.

## ಸಂಶೋಧನಾ ಬಳಕೆಗೆ ಮುನ್ನ ಬಾಕಿ ಇರುವ ಕೆಲಸ

1. 270 ನಿಜವಾದ ಮತ್ತು 270 ಕಲ್ಪಿತ ಕನ್ನಡ ಪದಗಳನ್ನು ಸಂಶೋಧನಾ ತಂಡದಿಂದ ಸ್ವೀಕರಿಸಿ ಪರಿಶೀಲಿಸುವುದು.
2. ಪದಗಳ ಭಾಷಾ ಗುಣಲಕ್ಷಣ, ವಯಸ್ಸು/ತರಗತಿ ಸೂಕ್ತತೆ, ಉಚ್ಚಾರಣೆ/ಅಕ್ಷರ ಸಂಯೋಜನೆ ಮತ್ತು ಕಲ್ಪಿತ ಪದಗಳ ಮಾನ್ಯತೆಯನ್ನು ಪರಿಶೀಲಿಸುವುದು.
3. ಆರು ಸೆಷನ್‌ಗಳ ಕ್ರಮ, ಅಭ್ಯಾಸ ಪದಗಳು, ವಿರಾಮ/ಪ್ರೋತ್ಸಾಹ ಮತ್ತು ಪ್ರತಿ ಭೇಟಿಯ ವೇಳಾಪಟ್ಟಿಯನ್ನು ಪ್ರೋಟೋಕಾಲ್‌ನಲ್ಲಿ ದೃಢೀಕರಿಸುವುದು.
4. ಕನ್ನಡದ ಅಕ್ಷರ ವಿನ್ಯಾಸ ಮತ್ತು ವಿವಿಧ ಸಾಧನ/ಬ್ರೌಸರ್‌ಗಳಲ್ಲಿ ಪಠ್ಯ ಪ್ರದರ್ಶನ ಪರೀಕ್ಷಿಸುವುದು.
5. ಪರೀಕ್ಷಾ ಮರುಪರೀಕ್ಷೆ, ಬಳಕೆದಾರ ಪರೀಕ್ಷೆ, ಪೈಲಟ್ ಮತ್ತು ಮನೋಮಿತೀಯ ಮಾನ್ಯತೆ/ವಿಶ್ವಾಸಾರ್ಹತೆ ಅಧ್ಯಯನ ನಡೆಸುವುದು.
6. ಸುರಕ್ಷಿತ ಭಾಗವಹಿಸುವವರ ಪ್ರೊಫೈಲ್, ಆಕ್ಸೆಸರ್ ಪ್ರವೇಶ, ಸರ್ವರ್ ಡೇಟಾಬೇಸ್ ಮತ್ತು ರಫ್ತು ವ್ಯವಸ್ಥೆ ನಿರ್ಮಿಸುವುದು.
7. ಸಂಶೋಧನಾ ನೈತಿಕ ಸಮಿತಿ/ಸಂಸ್ಥೆಯ ಅನುಮೋದನೆ ಮತ್ತು ಡೇಟಾ ಸಂರಕ್ಷಣಾ ಕ್ರಮಗಳನ್ನು ಖಚಿತಪಡಿಸುವುದು.

## ತಾಂತ್ರಿಕ ವಿನ್ಯಾಸ

- Vite ಮೂಲಕ ನಿರ್ಮಿಸಲಾದ ಸ್ವತಂತ್ರ ಫ್ರಂಟ್‌ಎಂಡ್.
- ಸರಳ JavaScript ಮಾಡ್ಯೂಲ್‌ಗಳು; ಪದಪಟ್ಟಿ ಓದು/ಪರಿಶೀಲನೆ ಪ್ರತ್ಯೇಕ ಮಾಡ್ಯೂಲ್‌ನಲ್ಲಿ.
- ಪ್ರೋಟೋಕಾಲ್ ಮತ್ತು ಪರೀಕ್ಷಾ ಪದಗಳ ಡೇಟಾ ಕೋಡ್‌ನಿಂದ ಪ್ರತ್ಯೇಕ CSV ರೂಪದಲ್ಲಿ.
- Vercel ಮೂಲಕ ಸ್ಥಿರ ಫ್ರಂಟ್‌ಎಂಡ್ ಹೋಸ್ಟಿಂಗ್.

ಈ ಯೋಜನೆ ROAR ವೆಬ್ ಅಪ್ಲಿಕೇಶನ್‌ನಿಂದ ಪ್ರೇರಿತವಾದ ಸ್ವತಂತ್ರ ಅನುಷ್ಠಾನ. ROAR‌ನ ಮೂಲ ಕೋಡ್ ಅಥವಾ ಅದರ ಪರವಾನಗಿ ನಿರ್ಬಂಧಿತ ಭಾಗಗಳನ್ನು ಇಲ್ಲಿ ನಕಲಿಸಲಾಗಿಲ್ಲ. ROAR ಮೂಲ ಕೋಡ್ ಅನ್ನು ಆಧರಿಸಿ ರೂಪಾಂತರ/ವಿತರಣೆ ಮಾಡುವ ಮೊದಲು ಸಂಬಂಧಿತ ಹಕ್ಕುದಾರರಿಂದ ಲಿಖಿತ ಅನುಮತಿ ಪಡೆಯಬೇಕು.

## ಕೊಡುಗೆ ಮತ್ತು ಪ್ರತಿಕ್ರಿಯೆ

ಮೊದಲ ಹಂತದಲ್ಲಿ ಲಾಂಚ್ ಪರದೆ, ಸೂಚನೆಗಳು, ಪದ ತೋರಿಸುವಿಕೆ, ಉತ್ತರ ಆಯ್ಕೆ, ಪ್ರಗತಿ, ವಿರಾಮ ಮತ್ತು CSV ಫಲಿತಾಂಶಗಳ ಬಳಕೆದಾರ ಪರಿಶೀಲನೆ ಮಾಡಿ. ನಂತರ ಪ್ರತಿ ವಿಭಾಗದ ಪ್ರತಿಕ್ರಿಯೆಯ ಆಧಾರದ ಮೇಲೆ ಪ್ರತ್ಯೇಕವಾಗಿ ಸುಧಾರಿಸೋಣ.
